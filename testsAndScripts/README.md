# Tests and Scripts

This directory contains utilities for development, debugging, and validation of the rover system.

## Included utilities

- GPS serialization and receiver tests.
- Rover motor control and controller debugging scripts.
- Simulated coordinate and telemetry experiments.
- Vision and camera test helpers for the perception stack.

## Usage

Use these scripts as debugging aids while validating hardware interfaces, serial communication, or vision behavior. They are not intended to be the primary deployment entry points.
